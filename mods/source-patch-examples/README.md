# 电脑重建示例

这些 ZIP 不能用手机统一导入入口安装：

- `example-code-mod.zip`：格式 2 源码补丁示例
- `global-image-background.zip`：格式 2 全局图片背景源码补丁
- `restore-original.zip`：恢复基线的重建请求

保留其原始文件，实际使用必须核对包内 `baseId` 和对应基线。说明见 [源码补丁格式](../../project-specs/import-formats/source-patch-zip.md)。手机安装请选择 `imported-modules/mods/` 的格式 3 运行时 Mod。
