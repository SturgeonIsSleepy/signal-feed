# APK 工作流与分支边界

SignalFeed 的 APK 会覆盖手机上正在使用的应用。为了避免分支任务误生成或替换安装包，所有代码对话遵守以下约定：

1. 分支对话、子任务和临时工作树只处理源码、配置和项目文档，不构建、替换、签名、安装或提交 APK。
2. 只有主对话在当前任务中收到用户明确要求后，才处理 APK；构建、签名、安装等操作也由主对话完成。
3. 分支任务需要 APK 验证时，检查源码或提交可审阅的改动，并把待验证事项交给主对话，不自行产出 APK。
4. 所有 `.apk` 文件由 `.gitignore` 忽略。GitHub Pull Request 检查拒绝任何 APK 文件变更，防止安装包混入源码提交。
5. 导入格式说明仅在 `project-specs/import-formats/` 保存和维护，不复制到 Android assets，不进入 APK。

这些规则约束对话和仓库协作流程；分支对话不得通过改名、压缩或其他方式绕过 APK 文件检查。
