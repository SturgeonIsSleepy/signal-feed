# 信息流筛选规则

## 给 AI 的生成要求

请按 SignalFeed 筛选规则格式生成一个 UTF-8 JSON 文件，只匹配我明确描述的内容。需要账号或主题时，使用我给的实际 ID，不要猜测。每条规则都必须有至少一个有效条件。文件扩展名为 `.json`。

## JSON 格式

```json
{
  "formatVersion": 1,
  "id": "hide-empty-posts",
  "name": "隐藏空内容",
  "description": "过滤没有实质正文的帖子",
  "rules": [
    {
      "action": "hide",
      "topics": ["全球"],
      "keywords": ["敬请期待", "更多内容稍后发布"]
    },
    {
      "action": "allow",
      "accounts": ["f1"]
    }
  ]
}
```

- `formatVersion`：必填整数 `1`。
- `id`：必填，1 至 64 位英文字母、数字、下划线或短横线。同 ID 再导入会替换旧配置。
- `name`：必填，1 至 80 个字符。
- `description`：可选说明。
- `rules`：必填数组，1 至 100 条。
- `action`：每条必填，`hide` 隐藏命中帖子，`allow` 保留命中帖子并停止后续规则判断。
- `accounts`、`topics`、`keywords`：可选字符串数组。同一数组内任一值命中即可。
- `bodyRegex`：可选 JVM 正则表达式，最多 240 个字符，在正文前 5,000 字符内搜索。

一条规则中提供的多个条件类别按“同时满足”处理；没有填写的条件类别不限制。规则按导入顺序判断，首个命中规则决定隐藏或保留；所有规则均未命中时显示帖子。关键词区分不敏感大小写。不要使用空条件规则，也不要编写可能匹配所有正文的正则。
