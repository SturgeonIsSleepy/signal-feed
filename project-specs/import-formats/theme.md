# 主题包与语言字典

主题包是 UTF-8 JSON，可组合配色和附加语言。一次启用一个主题，导入后在「语言与外观」选择语言和浅色、深色或跟随系统。

```json
{
  "formatVersion": 1,
  "type": "theme-pack",
  "name": "午夜蓝",
  "light": {
    "primary": "#1D9BF0", "background": "#FFFFFF", "surface": "#FFFFFF",
    "text": "#0F1419", "secondary": "#536471", "line": "#EFF3F4", "muted": "#F5F8FA"
  },
  "dark": {
    "primary": "#176C9F", "background": "#090D12", "surface": "#10171F",
    "text": "#E7E9EA", "secondary": "#9BA9B5", "line": "#25313C", "muted": "#18222D"
  },
  "languages": [
    {
      "code": "ja", "name": "日本語",
      "strings": {
        "首页": "ホーム", "数据": "データ", "设置": "設定",
        "为你推荐": "おすすめ", "正在关注": "フォロー中",
        "选择车手（{selected}/{total}）": "ドライバーを選択（{selected}/{total}）"
      }
    }
  ]
}
```

## 配色字段

- `formatVersion`：必填整数 `1`。
- `type`：建议 `theme-pack`，支持仅含语言字典的主题。
- `name`：可选显示名。
- `light`、`dark`：可选配色对象，值均为完整 `#RRGGBB`。
- 七个颜色键：`primary` 强调色，`background` 页面底色，`surface` 内容表面，`text` 主文字，`secondary` 次要文字，`line` 分隔线，`muted` 标签及弱强调背景。

缺省颜色使用应用对应浅色或深色默认值。兼容把颜色放在根对象的旧主题，这些颜色仅用于浅色；若有 `light` 则优先使用整个 `light` 对象。深色只读取 `dark`。按钮选中时使用白色文字，`primary` 要与白色保持对比。主题不会覆盖图表中的车手识别色或原始 PDF 页面。

配色包不接受图片、字体文件或布局代码，需要这些能力时使用 [手机 Mod](runtime-mod-zip.md)。模糊和滚动隐藏顶栏可在设置单独关闭；模糊使用 Android 12 及以上系统效果，低版本显示普通背景。

## 附加语言

`languages` 最多 20 项，每项有：

- `code`：唯一语言代码，例如 `ja`、`fr`、`pt-BR`。2 至 3 位小写字母，可接区域代码，不可覆盖内置 `zh` 或 `en`。
- `name`：1 至 80 个字符的显示名。
- `strings`：1 至 1,000 个键值。键是现有中文界面文案，1 至 2,000 字符；值为对应译文，1 至 4,000 字符。

动态文案使用 `{count}` 这类英文字母占位符。键和值的占位符集合必须完全相同，键至少包含固定文字，不能只有占位符。文案必须完整匹配，不使用模糊替换。完整内置英文映射位于源码 `app/src/main/java/cc/ccwu/signalfeed/EnglishStrings.kt`，可以用其中文键制作完整字典。缺少的词条回退到英文，未收录的文案保留原文。

语言字典只翻译界面，正文由内置设备端翻译器按目标语言自动处理。附加语言如不被翻译模型支持，正文保留原文。关闭自动翻译不影响界面语言。

移除主题恢复默认配色；若当前语言来自已移除主题，界面回到中文。更换主题不合并旧字典，需要保留的语言应一起放入新主题。
